CAN 总线

CAN 是一种“多主、广播、差分”的串行总线：所有节点挂在同一对线上，谁先抢到总线谁发言，靠报文 ID 而不是地址来决定优先权。

它让几十个 ECU 用两根线就能互相通信，且在电磁噪声极强的汽车环境里几乎不出错——这正是它统治车载网络 40 年的原因。

01它是什么

CAN（Controller Area Network）由博世在 1986 年为汽车电子开发，1993 年成为国际标准 ISO 11898。它是一套物理层 + 数据链路层规范：物理层规定了差分信号怎么发，链路层规定了帧怎么组、冲突怎么解、错误怎么查。

一句话类比
CAN 总线像一间会议室：谁想发言就先举手（拉低总线），如果几个人同时举手，就看谁要说的“事”更紧急（ID 更小）——紧急的人先说，其他人自动闭嘴等下一轮。没有一个主持人分配发言权。

02为什么需要它

在 CAN 之前，汽车线束是点对点的：每增加一个功能就要多拉一组线。一台车动辄几公里线束、上百公斤铜。CAN 用两根线承载所有 ECU 的通信，把线束重量和成本砍掉一大截，同时解决了“多个节点同时想说话怎么办”。

维度没有它时有了它之后
线束每功能一组线，几公里长两根双绞线走全车
扩展性加功能就要重新布线新节点并联挂上即可

03核心原理

CAN 的三个核心设计是：差分传输（抗干扰）、非破坏性仲裁（冲突不丢包）、广播通信（一发多收）。下面先看一帧数据从产生到被接收的完整链路。

04关键机制

① 差分信号：为什么两根线比一根线抗干扰

CAN 用 CAN_H 和 CAN_L 两根线，接收端判断的是两者的电压差而不是对地电压。外部电磁干扰会同时叠加到两根线上（共模干扰），相减就抵消了；真正的信号（差模）被完整保留。显性位（逻辑 0）差值约 2V，隐性位（逻辑 1）差值约 0V。

类比
就像两个人同时被风吹得往同一边晃，但只要看他们之间的相对距离，风的影响就消失了。

② 优先级：ID 越小越优先，而且冲突不丢数据

CAN 用“线与”逻辑：只要有一个节点发显性位（0），总线就是 0。仲裁发生在 ID 字段，各节点边发边听——谁发的是隐性位（1）却读回显性位（0），就说明有更高优先级的节点在说话，自己立刻退让。退让方没有损失，下一轮总线空闲时可以直接重发。

06常见误区

常见误解实际情况
“CAN 需要主节点来调度，谁先发由主机决定”CAN 是多主架构，没有主机。任何节点在总线空闲时都可以主动发送，优先级由报文 ID 决定。
“两个节点同时发送会撞车、数据损坏，必须重传”仲裁是非破坏性的：优先级低的节点在 ID 阶段就主动退出，总线上的位不会被破坏，高优先级帧完整发出。

07进阶与延伸

学完基础后，建议按这个顺序继续：CAN FD（可变速率、最大 64 字节负载）、CANopen（应用层协议，工业与汽车常用）、以及车载以太网（SOME/IP）。

  • CAN FD：数据段可提速到 5–8 Mbps，单帧最多 64 字节
  • CANopen / J1939：在 CAN 之上定义的应用层规范
